# Proyecto 2: Resumen Ejecutivo de Ventas Walmart

**Objetivo:** Analizar las ventas de Walmart para identificar departamentos con mayor participación y variación semanal.

### Herramientas
- Google Sheets / Excel
- Tablas dinámicas
- Gráficos y Dashboard

### Qué hice
- Limpieza de 3 bases: raw_ventas, raw_departamento, raw_tiendas
- Cálculo de participación por departamento y variación semanal
- Creación de Dashboard ejecutivo
